# Séance différenciée : « La vie dans une ruche » (3e secondaire, français, 50 min)

Profil utilisé : classe 3B (fictive), valable jusqu'au 2026-11-04. Aucun élève identifié, aucun aménagement attribué à une personne.

Notation dans les documents : `==mot==` = mot à surligner en fluo à l'impression. Police de tous les documents : Arial 14, marges larges, une consigne par ligne, zones de réponse délimitées. Chaque ligne du texte = une phrase numérotée.

---

## ANALYSE DU CONTENU FOURNI

**Collecte (étape 0)** : 3e secondaire, français, texte informatif, 50 min, classe entière, feuilles A4, pas d'aide humaine. Référentiel : compétence terminale 2e degré « lire / dégager l'idée principale », **à confirmer par l'enseignant** (non vérifié ici). Réseau et filière : non précisés, sans incidence sur la production.

**OBJECTIF COMMUN** : Dégager l'idée principale d'un texte informatif et la justifier par au moins deux informations relevées dans le texte.

**Analyse sur 5 axes**

| Axe | Constat sur le texte et les exercices d'origine |
|---|---|
| Charge lexicale | Texte court (12 phrases, 110 mots environ), phrases courtes. Mots à définir : butiner, larve, nectar, pollen, ouvrière, faux-bourdon, s'accoupler. Aucune difficulté syntaxique. |
| Charge cognitive | L'exercice 1 empile trois actions (lire, souligner, dire de quoi ça parle). L'exercice 4 demande une inférence (« ne pourrait pas fonctionner sans »). |
| Étayage fourni | Aucun : pas d'exemple, pas de lignes numérotées, pas de modèle de réponse. |
| Complexité | Idée principale implicite (jamais énoncée telle quelle) : risque de confondre sujet, détail (le miel) et idée principale. |
| Production | Orale (ex. 1), relevé (ex. 2), tableau (ex. 3), explication écrite (ex. 4). |

**Adaptations transversales (profil de classe)** : appliquées aux trois versions, jamais à une seule.
- Consigne donnée AVANT le support : chaque document est en deux parties, la feuille « Consignes » (distribuée et expliquée d'abord) puis la feuille « Texte » (distribuée après).
- Consignes épurées : un verbe d'action par ligne, sans commentaire.
- Exemples concrets dans les consignes (AU) et reformulation.
- Lignes numérotées, mots-clés en fluo, carte mentale, Arial 14.
- Texte envoyé la veille (préparation à domicile) : voir guide enseignant.
- Lecture à voix haute : voir « Points de décision » dans le guide. Aucun élève n'est appelé à lire à voix haute dans ces documents.

## DOCUMENT BLEU (Accès sécurisé)

### Feuille 1 : Consignes (à distribuer en premier, avant le texte)

**La vie dans une ruche, document bleu**
Nom : ______________________  Date : ______________

**Ce que je vais apprendre** : Dégager l'idée principale d'un texte informatif et la justifier par au moins deux informations relevées dans le texte.
En clair : je trouve de quoi parle le texte en une phrase, et je montre où je le lis.

**Ce dont j'ai besoin** : le texte (feuille 2), un crayon, un surligneur.

**Exemple pour comprendre** (autre texte) :
Texte : « Le facteur trie le courrier. Il le porte dans les boîtes. Il roule en vélo. »
Idée principale : le facteur apporte le courrier.
Preuve : ligne 2, « Il le porte dans les boîtes ».

**Ce que je fais (dans l'ordre)**

1. Lis le texte en silence.
2. Regarde les mots en fluo.
3. Coche l'idée principale.
4. Recopie deux preuves.
5. Remplis le tableau.
6. Complète la carte mentale.
7. Termine la phrase finale.

**Mon aide** : banque de mots, lignes numérotées, mots expliqués sous le texte.

### Feuille 2 : Texte (à distribuer après les consignes)

**La vie dans une ruche**

1. Une ==ruche== abrite des dizaines de milliers d'==abeilles==.
2. Elles ne font ==pas toutes le même travail==.
3. La ==reine== est la seule abeille qui ==pond des œufs==.
4. Elle peut en pondre ==plus de mille par jour== au printemps.
5. Les ==ouvrières== sont des femelles.
6. Elles ==nettoient== la ruche, ==nourrissent== les larves et ==défendent== l'entrée.
7. Les plus âgées sortent ==butiner==.
8. Elles récoltent le ==nectar== et le ==pollen== des fleurs.
9. Avec le nectar, les abeilles fabriquent le ==miel==.
10. Les mâles s'appellent des ==faux-bourdons==.
11. Ils ne récoltent rien et ne piquent pas.
12. Leur rôle est de ==s'accoupler== avec une reine.

**Mots expliqués**
- larve : bébé abeille, qui ne vole pas encore.
- butiner : aller sur les fleurs pour récolter.
- nectar : liquide sucré des fleurs.
- pollen : poudre jaune des fleurs.
- s'accoupler : se mettre en couple pour avoir des petits.

### Feuille 3 : Mes réponses

**1. Coche l'idée principale du texte.**
- [ ] a) Comment les abeilles fabriquent le miel.
- [ ] b) Chaque sorte d'abeille a son propre travail dans la ruche.
- [ ] c) Les dangers qui menacent les abeilles.

**2. Recopie deux preuves.** Aide : regarde les lignes 2, 3 et 6.
- Preuve 1 : ligne ____ : « ______________________________ »
- Preuve 2 : ligne ____ : « ______________________________ »

**3. Rôle de la reine. Relève deux informations.** Aide : lignes 3 et 4.
- Information 1 : La reine _______________________________
- Information 2 : Elle peut _____________________________

**4. Complète le tableau.** Banque de mots : pond des œufs / nettoient la ruche / butinent / s'accouplent avec la reine / défendent l'entrée / ne piquent pas.

| Qui ? | Ce qu'il ou elle fait | Ligne(s) |
|---|---|---|
| La reine | | 3 |
| Les ouvrières | | 6, 7 |
| Les faux-bourdons | | 12 |

**5. Complète la carte mentale.** Écris un mot ou une courte expression dans chaque case vide.

```
                 [ La reine ] -> [ __________ ]
                       |
[ Les faux-bourdons ] -- LA RUCHE -- [ Les ouvrières ] -> [ ________ ] [ ________ ] [ ________ ]
        |
 [ __________ ]
```

**6. Termine la phrase.**
Sans les ouvrières, la ruche ne pourrait pas fonctionner, parce que ______________________________.
Aide : relis la ligne 6.

## GUIDE ENSEIGNANT

**Séance : La vie dans une ruche. 3e secondaire, français, 50 min. 2026-10-05.**

**OBJECTIF COMMUN** : Dégager l'idée principale d'un texte informatif et la justifier par au moins deux informations relevées dans le texte.
**Référentiel** : compétences terminales, 2e degré, lecture. Référence exacte à confirmer par toi (non vérifiée ici).

**Correspondance couleur / niveau** (à ne pas dire aux élèves) : bleu = accès sécurisé, vert = maîtrise attendue, orange = approfondissement.

**Organisation suggérée** : classe entière, trois documents distribués sans commentaire sur les couleurs. Recommandé : les élèves choisissent ou tu proposes discrètement, avec droit de changer en cours de séance. Pas de note sur ces documents (formatif).

**Répartition** (à adapter, classe sans effectif connu) : bleu, environ un quart de la classe ; vert, environ la moitié ; orange, environ un quart. Le profil donne des tranches d'aménagements, pas des élèves : ne rattache aucun aménagement à un niveau. Les aménagements sont déjà dans les trois versions.

**Ce qui diffère**

| Axe | Bleu | Vert | Orange |
|---|---|---|---|
| Idée principale | QCM de 3 propositions + phrase de preuve à compléter | Phrase libre + deux lignes citées | Phrase libre + tri idée principale/détail + inférence non écrite |
| Étayage | Exemple résolu, lignes suggérées, banque de mots, glossaire | Exemple résolu, lignes numérotées | Exemple, aucun indice de ligne |
| Tableau | Phrases à compléter avec banque | Tableau libre | Colonne supplémentaire (conséquence de l'absence) |
| Ouvrières | Amorce « parce que... » | 2-3 phrases | 3-4 phrases, deux lignes citées |
| Carte mentale | À compléter | À construire (3 branches) | Liens étiquetés entre branches |
| Extension | aucune | aucune | Texte 2 (transfert), comparaison, bonus titre |

**Identique** : le texte numéroté et surligné, l'objectif, les aménagements de classe.

**Gestion du temps (50 min)**
- 5 min : lancement. Tu énonces l'objectif et les consignes AVANT de distribuer les textes (feuille 1 seulement). Montre l'exemple du facteur au tableau.
- 5 min : distribution du texte (feuille 2), lecture silencieuse.
- 30 min : travail individuel ou en duos.
- 10 min : mise en commun. Fais verbaliser : « Quelle est l'idée principale ? Quelle ligne le prouve ? »

**Signaux d'alerte**
- Bleu bloqué dès le départ : relis-lui la consigne 3 avec l'exemple du facteur, puis oriente vers la ligne 2.
- Orange termine tôt : texte 2 (feuille 4), bonus titre, ou rédiger un contre-exemple de détail.
- Refus du document : « tu changes quand tu veux », échange discret, sans commenter la couleur.

**Liens skills** : /au-reformatage si besoin de normes AU strictes ; /aristotle-inclusif pour un élève précis ; /eval-adaptee pour la suite évaluative ; /quiz-ipad pour une mise en commun interactive.

**Évaluation** : formative. Observables : cite une ligne pour justifier ; distingue idée principale et détail ; n'attribue pas à la reine un pouvoir non écrit dans le texte (orange).
